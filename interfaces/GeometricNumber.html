    Interface GeometricNumber<I, M, S, V, MAGNITUDE, SCALING, UNIT>

    This interface is provided to ensure consistency. Notice that the effect on the target depends upon whether the target class in mutable. I: The lightweight interface form of the concreate class, usually just coordinates. M: The concrete class S: The lightweight interface form of the spinor. V: The lightweight interface form of the vector. MAGNITUDE: The type for methods that compute magnitudes.
